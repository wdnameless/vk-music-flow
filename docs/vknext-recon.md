## 🔑 Ключевое открытие: как получаются ссылки

Проверено на живом профиле:

- `audio.get` / `audio.getById` / `catalog.getAudio` (и `api.vk.ru`, и `web.api.vk.ru`) возвращают **`"url": ""`** — **ноль** медиа-ссылок.
- `al_audio.php` (`reload_audios`, `get_audio`, все форматы id) ссылок **не отдаёт**.
- `track_code` не превращается в URL прямой подстановкой (проверил — 204/отказ).
- **Веб-клиент VK сам получает `url: ""`** — я перехватил его `batch.call` (135 КБ) и медиа-URL там **нет ни одного**.

**Вывод:** и оригинал, и веб-клиент берут играбельный URL **лениво, в момент воспроизведения**. Это тот же HLS (AES-128), который ловит наш сетевой хук. Поэтому:

- наш даунлоадер (хук → m3u8 → AES-128 → ID3) **уже совместим** с их плеером;
- для нового проекта нужен собственный слой «получить ссылку по (owner_id, id, access_key) в момент запроса» — и он не сводится к одному API-вызову.

## 🔑 Ключевое открытие №2: авторизация невозможна без DNR

Проверено в залогиненном профиле, из extension-контекста:

```
web_token → 200 {"type":"error","error_code":"","error_info":"wrong origin"}
```

`Origin` — **запрещённый для fetch заголовок**; задать его скриптом нельзя. Именно поэтому у vknext правило №1 — DNR подставляет `Origin: https://vk.ru/`. Без `declarativeNetRequest` tabless-авторизация VK не работает в принципе.

## DNR-правила (нужны нам в той же роли)

```
1  Origin: https://vk.ru/  → login.vk.ru?act=web_token      ← без него нет токена
2  Origin: https://vk.ru/  → vk.ru/al_audio.php?*
3  Origin: https://vk.ru/  → api.vk.ru/*
4  UA Genius/4.2.1 (Android) → api.genius.com
5  снять X-Frame-Options + CSP (для встраивания/доступа)
6  CORS + Origin для zvuk.com
7  редирект vk.com → vk.ru
```

## Честные риски

- Ссылки ленивые: скачивание трека, который ни разу не игрался, требует сначала получить его URL — нужен явный шаг резолва (в оригинале не решено, т.к. он не качает).
- `access_token` привязан к сессии VK в браузере; при выходе — переавторизация.
- VK меняет эндпоинты (домен .com → .ru уже меняли) — слой API надо изолировать.
- Реверс-инжиниринг их бандла — только как источник понимания механики (client_id, спуфы) — юридически спорный; код пишем свой.
