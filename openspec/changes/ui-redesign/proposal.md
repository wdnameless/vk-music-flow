# UI-переработка: иконки, плеер, темы, настройки

Человекочитаемый план. Детали — в tasks.md и interfaces.md.

## Куда идём

Интерфейс доводится до премиума по пяти прямым требованиям: целые иконки,
плеер с настраиваемой позицией и симметрией, игра по клику на строку,
светлая/тёмная темы, удобные настройки.

## Срезы

1. **Иконки (R01)** — `<g>` → `<symbol viewBox="0 0 24 24">` в спрайте;
   визуальная проверка каждого use.
2. **Плеер (R02, R03)** — настройка `playerBarPosition: top|bottom`,
   grid-раскладка сверху/снизу, транспорт строго по центру, симметрия
   мета/громкости.
3. **Клик-по-строке (R04)** — клик по строке играет; чекбокс и кнопки —
   исключения. Даблклик/текстовыделение не ломаются.
4. **Темы (R05)** — CSS-переменные под `[data-theme]`, `auto` от
   `prefers-color-scheme`, ручной выбор в настройках, персистентность.
5. **Настройки (R06)** — группы-аккордеоны: Звук / Загрузки / Сеть /
   Last.fm / Вид. Существующие контролы переезжают без смены логики.

## Границы

Не входит: новые фичи, редизайн видов, смена SW-контрактов (кроме чтения
настроек вида).
