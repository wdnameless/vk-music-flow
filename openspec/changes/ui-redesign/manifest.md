# Манифест: UI-переработка (2026-10-23)

Источник цитат — дословные слова пользователя:
«Паломанные иконки везде плеер должна быть возможность поместить как наверх, так и вниз, он должен быть по центру, нету симметрии. Также неудобно выбирать треки я должен иметь возможность нажать на трек, и он сразу же бы проигрался. Также должна быть черная и белая тема. И настройки тоже неудобные.»

Решения Wave 0 (виджет): плеер = настройка+центрирование; клик = вся строка;
тема = авто+ручной; настройки = аккордеоны.

| ID  | Требование                                           | Цитата                                        | Статус |
| --- | ---------------------------------------------------- | --------------------------------------------- | ------ |
| R01 | Иконки рисуются целиком везде (sprite viewBox)       | «Паломанные иконки везде»                     | done   |
| R02 | Плеер можно поместить наверх или вниз (настройка)    | «поместить как наверх, так и вниз»            | done   |
| R03 | Плеер по центру, симметричная компоновка             | «он должен быть по центру, нету симметрии»    | done   |
| R04 | Клик в любом месте строки сразу играет трек          | «нажать на трек, и он сразу же бы проигрался» | done   |
| R05 | Чёрная и белая темы (авто от системы + ручной выбор) | «должна быть черная и белая тема»             | done   |
| R06 | Настройки группами-аккордеонами                      | «настройки тоже неудобные»                    | done   |

Границы (не входит): новые фичи плеера/загрузок; редизайн отдельных видов;
изменение message-контрактов SW (кроме чтения новых настроек вида).
