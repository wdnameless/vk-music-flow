# Манифест: главная по референсу в монотоне (2026-10-24)

Источник цитат — дословные слова пользователя:
«нужен такой интерфейс только в нашем стиле»

Решения Wave 0 (виджет): полный паритет секций; сайдбар +тема/профиль;
обложки цветные в моно-UI; плеер дефолт сверху, настройка жива.

| ID  | Требование                                                                                        | Дословная цитата        | Статус |
| --- | ------------------------------------------------------------------------------------------------- | ----------------------- | ------ |
| R01 | Главная компонуется секциями как на референсе: тайл-грид треков, полки плейлистов, жанры, похожие | «нужен такой интерфейс» | done   |
| R02 | Всё в монотонном стиле проекта (токены Noir, без цвета в хроме)                                   | «только в нашем стиле»  | done   |
| R03 | Жанры: чипсы поверх поиска по фиксированной таксономии                                            | «нужен такой интерфейс» | done   |
| R04 | Похожие треки: секция от seed-трека через target_audio с фолбэком                                 | «нужен такой интерфейс» | done   |
| R05 | Сайдбар: переключатель темы + подвал профиля (Friends/Upload — позже)                             | «нужен такой интерфейс» | done   |
| R06 | Обложки остаются цветными внутри монохромного UI                                                  | «нужен такой интерфейс» | done   |
| R07 | Плеер-бар дефолт сверху, настройка позиции сохраняется                                            | «нужен такой интерфейс» | done   |

Границы (не входит): Friends' music, Upload track, новые API сверх
target_audio/поиска, смена message-контрактов SW (кроме чтения настроек вида).
