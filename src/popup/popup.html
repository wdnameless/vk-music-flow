        Неудачные

          Прокси для VK

          Зарубежный доступ к ВКонтакте без сторонних прокси на весь браузер. В режиме «только VK» через прокси идут лишь домены ВКонтакте, остальной браузер работает напрямую.

          Список прокси

          Правила заголовков (DNR)

          Без подмены Origin ВКонтакте отвечает wrong origin на запросы из расширения: этот заголовок нельзя задать скриптом, только правилами браузера.

          Хранилище

          Режим «выбранной папки» пишет файлы напрямую в выбранную директорию на любом диске. Если Chrome снова спросит доступ — разреши его, файлы не уйдут в «Загрузки» молча.

          Вложенность поддерживается: Music/VK.

          Пропуск треков

          Артисты через запятую — их треки не будут играть.

          Last.fm (скробблинг)

          Получи ключи на last.fm/api и вставь их сюда. Затем нажми «Войти» — откроется страница авторизации, после неё нажми «Готово».
